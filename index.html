「Webコンテンツ作成」の成果

本テーマの学習目的

本テーマでは、HTML、CSS、JavaScriptの基本的な使い方を学び、それらを組み合わせてWebページを作成する技術を身につけることを目的とした。HTMLによるページ構造の記述、CSSによる見た目の設定、JavaScriptによる動的な処理について学習し、構文リファレンスを活用しながら理解を深めた。また、画像などのデータを組み合わせたWebページ制作を通して、Web技術の基礎と実践的な活用方法を習得することを目標とした。

プロジェクト課題について

プロジェクト課題では、八王子市のグルメ情報を検索できるWebページを作成した。利用者はプルダウンメニューからジャンルを選択し、検索ボタンを押すことで該当する店舗情報を表示できる。検索処理にはJavaScriptとAjax通信を利用し、axiosライブラリを用いてサーバからJSON形式のデータを取得した。取得したデータはDOM操作によって動的にページへ表示している。また、検索ボタンだけでなくEnterキーによる検索にも対応させ、キーボード操作でも利用しやすいよう工夫した。検索結果には店舗名、ジャンル、サブジャンル、住所、アクセス、営業時間、予算などを表示し、検索結果が0件の場合にはその旨を表示するようにした。さらに、再検索時には前回の検索結果を削除することで、結果が重複しないよう工夫した。CSSを利用して検索画面や検索結果のデザインを整え、見やすく利用しやすいページになるよう改善した。

プロジェクト課題で作成したページ: project.html

数当てゲーム

数当てゲームでは、JavaScriptを利用して乱数を生成し、その数を当てるゲームを作成した。コンピュータは1から10までの整数をランダムに選び、ユーザはテキストボックスに予想した数を入力して回答ボタンを押す。入力された値はJavaScriptで取得され、正解かどうか判定される。不正解の場合は、答えが予想より大きいか小さいかのヒントが表示される。また、予想回数を記録し、3回以内に正解できれば成功、できなければ失敗となる。今回の演習では、DOMを利用してHTML要素を書き換える方法や、イベント処理によってボタン操作に応じた処理を実行する方法を学んだ。さらに、条件分岐や変数を活用して、対話的なWebページを作成する技術を身につけた。

数当てゲームのページ: kazuate.html

各授業回の学習事項

第1回 WWW と HTML

第1回では、WWWとWebページの基本的な仕組みについて学習した。URLやHTTP通信の役割を理解するとともに、HTMLの要素、タグ、属性、文書構造について学んだ。また、ブロック要素とインライン要素の違い、ハイパーリンクや画像の埋め込み、特殊文字やコメントの記述方法について理解した。さらに、整形式なHTML文書を作成する重要性や、構文エラーと意味エラーの違いについても学習し、Webページ作成の基礎を身につけた。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

第2回では、CSSを用いてWebページの見た目を設定する方法について学習した。文字の色や大きさ、背景色などの変更方法を理解し、セレクタを用いて特定の要素を装飾する方法を学んだ。また、外部スタイルシート、内部スタイルシート、インラインスタイルの違いを理解し、CSSによる効率的なデザイン設定やデバッグの方法についても学習した。

演習の成果: 演習2-3: CSSによるWebページの装飾

第3回 JavaScript の基本

第3回では、JavaScriptの基本について学習した。JavaScriptとJavaの違いや、ブラウザ上でプログラムを実行する仕組みを理解し、コンソールを用いた実行やデバッグを行った。また、変数、関数、for-of構文、オブジェクトの利用方法を学び、undefinedやnullの意味、エラーの原因や対処方法についても理解を深めた。

演習の成果: 演習3-6: オブジェクトの利用

第4回 DOM と JavaScript

第4回では、DOMとJavaScriptを利用してWebページの内容を動的に変更する方法について学習した。input要素やbutton要素を用いて入力フォームを作成し、ユーザが入力した値をJavaScriptで取得する方法を理解した。また、document.querySelector()を利用してHTML要素を検索し、textContentやvalueを利用して要素の内容や入力値を参照・変更する方法を学んだ。さらに、DOMを利用することでHTML文書をプログラムから操作できることを理解し、テキストボックスに入力された値を利用した足し算プログラムなどを作成した。これにより、Webページに対話的な機能を追加する基礎技術を身につけた。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

第5回では、DOMを利用してWebページの内容を動的に変更する方法について学習した。具体的には、createElement()を用いて新しい要素を作成し、insertAdjacentElement()を利用して要素の内部や直後に追加する方法を学んだ。また、setAttribute()を用いて画像やリンクなどの属性を設定・変更する方法や、remove()によって不要な要素を削除する方法を理解した。さらに、button要素にクリックイベントを登録し、ボタンが押されたときにJavaScriptの関数を実行するイベント処理についても学んだ。これらの演習を通して、JavaScriptからHTML文書を自由に編集し、利用者の操作に応じてページの内容を変化させる仕組みを理解した。

演習の成果: 演習5-7: DOMの演習その2

第6回 通信処理（Ajax）

第6回では、Webページとサーバの間でデータをやり取りする通信処理について学習した。通常のWebページではリンクのクリックやページの再読み込みによって通信が行われるが、今回はAjax通信を利用してページ全体を更新せずに必要なデータだけを取得する方法を学んだ。通信にはaxiosライブラリを利用し、JavaScriptからサーバへリクエストを送信してJSON形式のデータを受け取る方法を理解した。また、通信成功時や失敗時の処理を関数として実装し、取得したデータをDOM操作によってページ上に表示する方法についても学習した。これらの演習を通して、利用者の操作に応じてサーバと通信しながら動的に内容を更新するWebアプリケーションの基礎技術を身につけた。

工夫点，苦心点，強調点，感想

本テーマを通して、HTML、CSS、JavaScriptを組み合わせてWebページを作成する技術を学んだ。特にプロジェクト課題では、これまでの講義で学習した内容を総合的に活用し、実際に利用できるグルメ検索ページを作成した。単に課題の要件を満たすだけでなく、利用者にとって使いやすいページとなるように工夫を行った。 プロジェクト課題における最も大きな工夫点は、検索方法をテキスト入力ではなくプルダウンメニューによるジャンル選択方式に変更したことである。課題で利用したグルメ情報の検索キーはあらかじめ決められたジャンルコードであったため、利用者がコードを覚える必要がなく、誤った入力も防げるようになった。これにより検索機能の使いやすさを向上させることができた。また、検索ボタンを配置し、利用者が直感的に操作できる画面構成を意識した。 さらに、Enterキーを押した場合でも検索が実行できるようにした。通常は検索ボタンをクリックする必要があるが、キーボード操作にも対応させることで利便性を向上させた。この機能は講義で学習したイベント処理を応用して実装したものであり、操作性の改善につながったと考えている。 検索結果の表示方法についても工夫した。取得したデータをそのまま表示するのではなく、店舗ごとに見出しを付け、アクセス情報、住所、予算、営業時間などを項目ごとに整理して表示した。これにより、多くの検索結果が表示された場合でも情報を確認しやすくなった。また、検索結果件数を表示することで、利用者が検索結果の数をすぐに把握できるようにした。 苦心した点は、Ajax通信を利用した検索機能の実装である。これまでの講義では主にHTMLやCSSによるページ作成、JavaScriptによるDOM操作を学習していたが、今回は外部サーバからデータを取得する処理が必要であった。axiosライブラリを利用して通信を行い、取得したJSONデータを解析して画面へ表示する流れを理解するのに時間がかかった。また、通信処理は非同期で実行されるため、通常のプログラムの流れとは異なる考え方が必要であり、動作確認を繰り返しながら理解を深めた。 検索結果の表示に関しても苦労した。最初は検索するたびに結果が追加されてしまい、以前の検索結果が残る状態になっていた。しかし、検索結果を表示する要素を削除してから新しい結果を表示する処理を追加することで問題を解決した。この経験を通して、DOM操作による要素の追加だけでなく削除の重要性についても理解することができた。 CSSによる装飾では、見やすさと統一感を意識した。背景色や文字色を暖色系で統一し、検索結果をカードのように表示することで視認性を向上させた。また、マウスを重ねた際に変化する効果や見出しの装飾を加えることで、学習したCSSの技術を積極的に活用した。機能だけでなく見た目にも配慮することが、利用しやすいWebページ作成につながることを実感した。 全体を通して、HTMLはページの構造、CSSは見た目、JavaScriptは動作を担当していることを実践的に理解することができた。また、DOM操作やイベント処理、Ajax通信などを組み合わせることで、利用者の操作に応じて動的に変化するWebページを作成できることを学んだ。今回の演習を通して、単なる知識としてではなく、実際にWebページを作成しながら技術を習得できたことは非常に有意義であった。今後はさらに高度なJavaScriptやサーバサイド技術についても学習し、より実用的なWebアプリケーションを開発できるようになりたいと考えている。
