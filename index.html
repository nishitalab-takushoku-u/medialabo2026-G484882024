各授業回の学習事項

第1回 WWW と HTML

第1回では、WebページとWWWの仕組みについて学んだ。URLやHTTP通信の基本を理解するとともに、Webページを構成するHTML、CSS、JavaScriptの役割を学習した。特にHTMLでは、要素、タグ、属性の意味や文書の基本構造について学び、簡単なWebページを作成するための基礎を習得した。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

第2回では、CSSを用いてWebページの見た目を変更する方法について学んだ。文字の色や大きさ、背景色、余白、枠線などの設定方法を理解し、HTMLとCSSを組み合わせてページを見やすく装飾する技術を習得した。また、外部スタイルシートを利用してデザインを一括管理する方法や、リンクや見出しの装飾についても学習した。

演習の成果: 演習2-3: CSSによるWebページの装飾
